# Upwork portfolio entry · LeadFlow Bridge v2.0

## English · copy directly into Upwork

**Title:** Python CSV to CRM REST API | Validation, Retries & Dashboard

**Role:** Python Developer & API Integration Engineer

**Description:**

**From inconsistent CSV files to reliable, duplicate-safe records.**

I developed this independent, AI-assisted Python reference project to demonstrate how I approach practical business automation and API integration. LeadFlow Bridge validates fictional contact data, normalizes input, sends authenticated REST requests and stores records in a local FastAPI CRM simulator with SQLite.

The integration handles temporary network failures through bounded retries, distinguishes new records from identical replays and rejects conflicting data. I also built an interactive, read-only dashboard that displays the records returned by the authenticated local API, together with automated regression tests, clear setup instructions and a repeatable end-to-end demo.

**Verified local results:** Four fictional contacts imported successfully; a second import created no additional records. The project includes 21 passing automated tests and an actual HTTP API/CLI smoke test.

**Technologies:** Python, FastAPI, HTTPX, Pydantic, SQLite, REST API, Pytest, HTML/CSS/JavaScript and GitHub Actions configuration.

**Transparency:** This is a self-initiated demonstration created with AI assistance and tested locally. It is not a paid client project, a live third-party CRM integration or evidence of financial results for a real business.

## Deutsch · sinngemäße Übersetzung

**Titel:** Python CSV zu CRM REST API | Datenprüfung, Wiederholungen und Dashboard

**Rolle:** Python-Entwickler und API-Integrationsentwickler

**Beschreibung:**

**Aus fehleranfälligen CSV-Dateien werden verlässlich übertragene Datensätze ohne doppelte Einträge.**

Ich habe dieses eigenständige, KI-unterstützte Python-Referenzprojekt entwickelt, um meine Arbeitsweise bei praktischer Automatisierung und API-Integration zu zeigen. LeadFlow Bridge überprüft fiktive Kontaktdaten, vereinheitlicht Eingaben, sendet authentifizierte REST-Anfragen und speichert sie in einer lokalen FastAPI-Demo mit SQLite.

Vorübergehende Netzwerkprobleme werden durch begrenzte Wiederholungsversuche behandelt. Das Programm erkennt bereits vorhandene Datensätze und weist widersprüchliche Änderungen unter derselben ID zurück. Dazu kommen ein interaktives, schreibgeschütztes Dashboard, automatisierte Regressionstests, eine dokumentierte Installation und ein reproduzierbarer vollständiger Probelauf.

**Lokal überprüft:** Vier fiktive Kontakte erfolgreich importiert. Beim zweiten Import wurden keine weiteren Datensätze erzeugt. Im Projekt sind 20 erfolgreiche Tests sowie ein tatsächlicher HTTP-Probelauf von API und Kommandozeile dokumentiert.

**Technologien:** Python, FastAPI, HTTPX, Pydantic, SQLite, REST API, Pytest, HTML/CSS/JavaScript und GitHub-Actions-Konfiguration.

**Wichtige Abgrenzung:** Eigenständig und KI-unterstützt erstellte, lokal getestete Demonstration. Kein bezahlter Kundenauftrag, keine produktive Anbindung an ein externes CRM und keine behaupteten finanziellen Kundenergebnisse.
